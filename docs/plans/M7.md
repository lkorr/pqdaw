## Core-structure decisions (approved by the user before launch)
1. **JI objects live in the note clip, next to its notes.** `NoteClip::ji` = sorted list of `JiObject`s: span, fundamental (an
   ordinary `PitchId`: Degree, Ratio or Cents), overtone/undertone flag, stops (exact integer terms + a fundamental multiplier + a
   transition each), an optional ride curve, the voices' note ids. Inner notes stay ordinary clip notes with
   `Harmonic(objectId, voiceIndex)` identity (Ratio anchored to `JiFundamental` also works). Nothing becomes a container.
2. **Playback is general: an object becomes long notes with per-note curves.** M7 adds per-note pitch and gain curves (SPEC §3.1,
   reserved by Q15) for EVERY note. Lowering turns an object into one note per voice (max(voice count)) over its span, each with a
   pitch curve (morph + ride, flattened into segments linear in cents) and a gain curve (1/k); inner notes get their voice's
   curve. The engine only learns "a note's pitch / gain moves along breakpoints" (Pitch ramps exist; a Gain ramp is new). No JI
   code in the engine.
3. **Unison phase: deterministic unisons first, a Sync event later.** Voices in unison from the object's start share onset, reset
   state and pitch curve → bit-identical lanes (phase already shared; a split is a clean clone). A voice merging into a
   neighbour later arrives with another phase: MVP parks it (fades to gain 0 over the merge, back in on split: no cancellation,
   no level jump). T7.7 adds a general `Sync` note event (copy another sounding voice's lane state, compaction's move); after it a
   merged voice is synced at gain 0 and gets exactly 1/k.
4. **Identities stay exact.** Every stop's pitch = integer term × rational fundamental multiplier (`voice.ratio` /
   `voice.harmonic` exact at holds); only the curve between holds is float cents; final pitch float32 Hz. Walk = stops whose
   multiplier keeps the pinned voice's pitch (exact rational). Undertone = 1/term.

## Data model (T7.2 owns it)
    struct JiShape { enum Kind : uint8_t { LogLinear, SCurve, Bezier } kind; float x1, y1, x2, y2; }  // bezier handles
    struct JiTiming { Ticks delay = 0; Ticks glide = 0; JiShape shape; }   // the transition INTO a stop
    struct JiStop {
      Ticks at;                          // content ticks from the object's start; stop 0 at 0
      std::vector<int64_t> terms;        // ascending, ≥ 1 term, each in [1, 2^20]
      tuning::Rational scale{1};         // fundamental multiplier (walk keeps a pinned voice's pitch)
      std::vector<uint8_t> voiceTerm;    // optional voice → term index (empty: spread rule)
      JiTiming timing;                   // default for every voice
      std::vector<std::optional<JiTiming>> voiceTiming;  // per-voice override
    };
    struct JiObject {
      JiObjectId id; Ticks start, length; tuning::PitchId fundamental;  // not Harmonic, not JiFundamental
      bool undertone = false, sounds = true;  // sounds=false: a scaffold, only inner notes play
      float velocity = 100.0f; std::vector<JiStop> stops; std::vector<Breakpoint> ride;  // cents, object ticks
      std::vector<NoteId> voiceNotes;          // size V = max terms over stops
    };
    struct NoteCurves { NoteId note; std::vector<Breakpoint> pitch; };  // cents offset, ticks from the note's start
    NoteClip: std::shared_ptr<const JiObjectList> ji; std::shared_ptr<const NoteCurveList> curves;  // sorted by id
- Spread rule: in a stop with n < V terms, voice v takes term ⌊v·n/V⌋; voices stay in pitch order; a voice "not needed" doubles a neighbour.
- Pure evaluation in `document/src/ji_object.cpp` (`pq/document/ji_object.h`), allocation-free per query: `jiVoiceCents(obj, v,
  tick)`, `jiFundamentalCents(obj, tick)`, `jiVoiceRatio(obj, v, stop)` (exact), `jiVoicePlan(obj, tolerance) → per voice {pitch
  segments, gain segments}`. Unison classes per hold / transition (same (from, to, timing) = identical). Gain ramps last
  min(glide, 20 ms). Roll, lowering and flattening all use this one function.
- Limits: ≤ 64 voices, ≤ 4096 stops per object (validated). Change class = Sequence (never recompiles).

## Tasks (≤ 2 workers; no shared files within a phase)

### T7.1 Engine: per-note pitch and gain curves (`engine` only)
- `NoteDesc::pitchCurve` / `gainCurve`: `std::vector<CurvePoint {Ticks tick; float value;}>` (content ticks; cents relative to `hz`
  / linear gain), piecewise linear. `SequenceImage`: flat `curves_` array, `Note::{curveBegin, pitchCount, gainCount}` (Note 72 →
  80 B; measure the sequence bench).
- `NoteEvent`: + `float gain = 1` at note-on; new kind `Gain {noteId, value, rampFrames}`. VoiceEngine `noteGain_` per lane with a
  linear ramp; lane gain = steal fade × note gain (mix, `VoiceGroupIO::gain`, reducers unchanged). A gain-0 lane is already
  invisible to `voice_last` and the max reducer (parked voices).
- Timeline: `Sounding` gets a curve cursor. At note-on (also seek / loop into the middle of a note) hz = the curve's value at that
  tick (binary search) and a ramp to the next breakpoint; a breakpoint inside the block emits Pitch / Gain ramped to the next
  (frames from the tempo map). One per-track "next curve sample" check per block. A swap keeps cursors by note id.
- Accept: a rendered note whose curve goes 0 → +702 ¢ → 0 tracks the analytic frequency within 0.01 ¢ (zero-crossing estimator) at
  block sizes 1/64/512; seek into the middle of a curve; loop pass; gain ramp ±0.01 dB; two notes with the same onset and curve are
  bit-identical lanes (compaction on); RtScope on process; interpreter == JIT.
- Verify: `-Affected -Slow`; sequence / voice bench rows (ship) before/after; ship link `pq_bench_dsp` once.
- CPU: work per breakpoint, not per sample (the per-sample glide exists); lanes without ramps keep the constant fill.

## Choices (recommended defaults)
- Pure-JI anchor: reference-anchored exact product when the anchor is a reference Ratio, else anchored to the note.
- Inner notes vs the chord: `sounds` flag per object (on by default; scaffold turns it off).
- Scale-steps layer when an (L, s) move isn't a degree: nearest degree + error shown.
- Note gain = lane gain (also weights `voice_sum` / reducers); a `voice.gain` signal later if wanted.
- Mapping moves in undo: one step per touch (coalesced). Merge before T7.7: park the merging voice.
- Hotkeys: JI tool `J`, Make JI object `Ctrl+Shift+J`, walk `Alt+Up/Down` (check clashes). Spread rule ⌊v·n/V⌋.
- Per-voice random state makes unisons decorrelated (−3 dB instead of coherent): accepted, documented.

## Risks
- Curve-event volume (64-voice object with vibrato) vs `maxEventsPerBlock` 1024: flatten tolerance + a test at the limit.
- Note-id ops that forget curves: T7.2 enumerates every op that creates ids.
- `SequenceImage::Note` 72 → 80 B: measure the timeline bench (PF rows).
- The CapsLock chord changes UiTree's modifier rule: test that CapsLock alone stays a non-chord.
