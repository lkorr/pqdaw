Scala .scl fixtures used by tests/tuning/test_scala.cpp and test_scale_tuning.cpp (T2.4).

All 28 files were authored for pqdaw and are written by tools/fixtures/gen_scl_fixtures.mjs (re-running it reproduces
them byte for byte). No file is copied from the Scala scale archive or anywhere else. The pitch sets are mathematical
facts (equal divisions, harmonic series, chains of pure intervals, temperaments computed from their definitions) or
plain published ratio lists; the descriptions and comments are our own text. Each file is laid out to cover .scl
edge cases seen in real files; .gitattributes marks *.scl -text so git keeps the exact bytes.
